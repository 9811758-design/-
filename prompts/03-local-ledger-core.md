# 단계 2~4 프롬프트 — 로컬 장부 핵심

```text
목적: 오프라인에서도 안전하게 저장되는 카페 장부의 입력·조회·집계 기능을 구현한다.

AGENTS.md와 docs/01-mvp-requirements.md부터 docs/07-test-strategy.md까지 읽어라. 현재 단계에서 요구되는 최소 기능만 구현한다.

구현 순서는 다음을 따른다.
1. IndexedDB schema와 repository, UUID·soft delete·migration·동기화 큐 모델
2. 재료 구매와 운영비 입력 및 신규 판매 입력 차단
3. 거래 내역의 기간 필터·수정·삭제
4. 대시보드와 통계의 총지출·비용 구분·카테고리·기간 추이 집계

금액 계산, 삭제 및 레거시 판매 제외, 오프라인 재시작 후 보존을 단위 테스트로 검증한다. 기존 판매·메뉴 데이터는 삭제하지 않는다. 단계가 끝날 때마다 빌드와 관련 테스트를 실행하고 다음 단계로 넘어갈 준비 상태를 보고하라.
```
