# 단계 5 프롬프트 — Google Sheets 동기화

```text
목적: 로컬에 저장된 장부 데이터를 Google Sheets에 중복 없이 안전하게 백업·동기화한다.

AGENTS.md와 docs/04-sync-and-backup.md를 반드시 먼저 읽어라. 로컬 데이터를 기준으로 Google 로그인, Sheet 선택 또는 초기 템플릿 생성, 동기화 큐, 재시도, UUID 중복 방지, 수정·soft delete 반영을 구현한다. 신규 원격 쓰기는 재료 구매와 운영비로 제한하고 기존 판매·메뉴 행은 변경하지 않는다.

Google API 오류·권한 거부·오프라인 상태에서 앱이 정상 동작해야 한다. 인증 비밀값은 코드에 넣지 않는다. 실제 API를 호출할 수 없는 자동 테스트에서는 API 어댑터를 모킹해 동기화 상태 전이와 중복 방지를 검증한다.
```
