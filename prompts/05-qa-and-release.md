# 단계 6~7 프롬프트 — QA와 출시 준비

```text
목적: 실제 카페 운영자가 모바일에서 장부를 기록해도 되는 수준으로 핵심 흐름을 검증하고 배포 준비를 마친다.

AGENTS.md와 docs/02-screens-and-flow.md, docs/07-test-strategy.md를 읽어라. 모바일 화면 크기에서 재료 구매·운영비 기록, 기간별 지출 통계, 동기화 실패 및 재시도 흐름을 E2E로 검증한다. 판매·메뉴 진입점이 없고 신규 판매 입력이 거부되는지도 확인한다.

빈 상태, 네트워크 없음, 잘못된 숫자 입력, API 오류, 동기화 지연을 확인한다. PWA 설치와 production build를 검증하고, 사용자에게 남은 운영 절차(Google OAuth 설정, Sheet 권한)를 문서화한다.
```
