# 화면과 흐름

## 정보 구조

하단 내비게이션은 다음 다섯 화면을 연결한다.

1. 대시보드
2. 기록
3. 내역
4. 통계
5. 설정

메뉴 관리 화면과 판매 기록 진입점은 없다.

## 대시보드

- 앱 로고와 오늘 총지출을 가장 먼저 보여 준다.
- 이번 달 총지출, 재료 구매비, 운영비, 거래 건수를 요약한다.
- 재료 구매 기록과 운영비 기록 버튼을 제공한다.

## 기록

1. 재료 구매 또는 운영비를 선택한다.
2. 유형에 맞는 필드를 입력한다.
3. 로컬 저장이 완료되면 성공 메시지를 표시한다.
4. 동기화가 설정된 경우 큐가 별도로 처리된다.

입력 오류가 있어도 사용자가 작성한 다른 값은 유지한다. 네트워크가 없어도 저장 흐름은 동일하다.

## 내역

1. 기간과 유형 필터를 설정한다.
2. 재료 구매와 운영비 목록을 확인한다.
3. 항목을 수정하거나 삭제한다.
4. 삭제는 soft delete로 처리되고 집계에서 즉시 제외된다.

## 통계

- 기간을 선택하면 총지출, 재료 구매비, 운영비, 거래 건수를 다시 계산한다.
- 운영비 카테고리별 금액·비중과 일별 지출 추이를 보여 준다.
- 데이터가 없으면 0원 지표와 명확한 빈 상태를 제공한다.

## 설정

- Google 계정 연결, Spreadsheet 선택·생성, 동기화 상태와 재시도를 제공한다.
- 동기화 문제는 로컬 기록과 분리해 안내한다.
