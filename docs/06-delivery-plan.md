# 전달 계획

## 현재 상태

지출 전용 전환 단계다. 재료 구매와 운영비 흐름을 유지하면서 메뉴 관리, 판매 입력, 매출·이익 집계를 제거하고 레거시 데이터 호환성을 검증한다.

## 단계

1. 제품 범위와 데이터 보존 정책 확정
2. 신규 판매 입력 차단 및 메뉴·판매 UI 제거
3. 기록·내역·대시보드·통계를 지출 전용으로 개편
4. Google Sheets 신규 쓰기를 구매·운영비로 제한
5. 회귀 테스트와 레거시 IndexedDB 마이그레이션 검증
6. README, 설계, 테스트 전략, 출시 체크리스트 갱신
7. lint, typecheck, unit, E2E, build, PWA 전체 검증

## 완료 기준

- UI에 메뉴 관리나 판매 진입점이 없다.
- 구매와 운영비의 저장·재실행 후 보존·수정·soft delete가 동작한다.
- 지출 지표와 기간 통계가 정확하다.
- 기존 판매·메뉴 데이터가 삭제되지 않고 앱이 정상 실행된다.
- 동기화 실패가 로컬 데이터 손실을 만들지 않는다.
- 저장소가 정의한 여섯 개 검증 명령이 모두 통과한다.
