# 전달 계획

## 현재 상태

날짜별 총매출과 월간 캘린더 단계다. 메뉴별 판매를 되살리지 않고 revenue를 추가하며 레거시 sale·menu 호환성을 검증한다.

## 단계

1. 제품 범위와 데이터 보존 정책 확정
2. 신규 revenue 타입과 영업일 upsert 추가
3. 기록·내역·대시보드에 총매출 추가
4. 접근 가능한 월간 매출·지출 캘린더 추가
5. Google Sheets 신규 쓰기를 revenue·purchase·expense로 제한
6. 회귀 테스트와 레거시 IndexedDB 마이그레이션 검증
7. README, 설계, 테스트 전략, 출시 체크리스트 갱신
8. lint, typecheck, unit, E2E, build, PWA 전체 검증

## 완료 기준

- UI에 메뉴 관리나 메뉴별 판매 진입점이 없다.
- 날짜별 총매출, 구매와 운영비의 저장·재실행 후 보존·수정·soft delete가 동작한다.
- 매출·지출 지표, 재료 구매비율과 월간 캘린더가 정확하다.
- 기존 판매·메뉴 데이터가 삭제되지 않고 앱이 정상 실행된다.
- 동기화 실패가 로컬 데이터 손실을 만들지 않는다.
- 저장소가 정의한 여섯 개 검증 명령이 모두 통과한다.
